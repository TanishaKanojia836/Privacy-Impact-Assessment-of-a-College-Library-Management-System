# 02 - Data Inventory

| Data | Purpose | Access |
|---|---|---|
| Student Name | Identify student | Student/Librarian |
| Student ID | Account identification | Student/Librarian |
| Email | Notifications | Student/Librarian |
| Phone Number | Communication | Authorized staff |
| Borrowing History | Library management | Student/Librarian |
| Return Date | Track returns | Librarian |
| Reservation History | Manage reservations | Student/Librarian |
| Fine Information | Manage fines | Student/Librarian |
| Login Information | Authentication | System/IT |
| Security Logs | Security monitoring | Authorized IT staff |

## Data Minimization

The system should collect only information necessary for library services.

For example, continuous GPS location is not required for normal library operations and should not be collected without a specific justified purpose.
