# 06 - Mitigation Strategies

| Risk | Mitigation |
|---|---|
| Unauthorized account access | Strong passwords and MFA |
| Database breach | Encryption and security monitoring |
| Excessive data collection | Data minimization |
| Excessive data retention | Retention and deletion policy |
| Unauthorized employee access | Role-based access control |
| Weak authentication | MFA and account protection |
| Vendor access | Appropriate contractual privacy and security controls |
| Accidental disclosure | Access controls and privacy-aware system design |

## Security Measures

The system should implement:

- Encryption
- HTTPS
- Strong authentication
- Multi-factor authentication
- Role-based access control
- Security logging
- Regular software updates
- Security testing
- Secure backups
